# AI SDK 6 examples

Optional, web-only; use the installed docs first. For provider-specific
behavior, find `examples/ai-functions/src/<function>/<provider>/<feature>.ts`
(apps: `examples/next`, `next-agent`) in the
[v6 examples](https://github.com/vercel/ai/tree/ai%406.0.297/examples), or at
the tag matching the app's installed release.

Repository main targets v7. Do not copy its text-function `instructions`,
`isStepCount`, `onEnd`, `toolApproval` or stateless response helpers into a v6
app. Replace demo model IDs/configuration with the app's actual values.
